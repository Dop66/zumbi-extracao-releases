# Aether Outbreak — Releases

Survival top-down em **mundo aberto procedural**: cidades para saquear, um
Altar de Poderes para despertar e Zumbis Magos à espreita.

**Site de download:** https://dop66.github.io/zumbi-extracao-releases/

## ⬇️ Baixar o jogo

**Windows:** [Baixar ZumbiLauncher.zip](https://github.com/Dop66/zumbi-extracao-releases/releases/latest/download/ZumbiLauncher.zip)

1. Extraia o `.zip`. Ele cria a pasta `ZumbiExtracao`.
2. Abra o `ZumbiLauncher.exe`. Ele baixa o jogo e o mantém sempre atualizado.
3. Clique em **Iniciar Jogo**.

Se o Windows mostrar "O Windows protegeu o seu computador", clique em **Mais informações → Executar assim mesmo**.

**Linux:** [Baixar zumbi-extracao-linux.zip](https://github.com/Dop66/zumbi-extracao-releases/releases/latest/download/zumbi-extracao-linux.zip), extraia e rode `./ZumbiExtracao.x86_64` (se precisar: `chmod +x ZumbiExtracao.x86_64`).
