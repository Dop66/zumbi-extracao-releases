# Zumbi Extração — Releases

## ⬇️ Baixar o jogo (Windows)

**[Baixar ZumbiLauncher.zip](https://github.com/Dop66/zumbi-extracao-releases/releases/latest/download/ZumbiLauncher.zip)**

1. Extraia o `.zip`. Ele cria a pasta `ZumbiExtracao`.
2. Abra o `ZumbiLauncher.exe`. Ele baixa o jogo e o mantém sempre atualizado.
3. Clique em **Iniciar Jogo**.

Se o Windows mostrar "O Windows protegeu o seu computador", clique em **Mais informações → Executar assim mesmo**.

Linux: baixe o `zumbi-extracao-linux.zip` na [página de releases](https://github.com/Dop66/zumbi-extracao-releases/releases/latest).
