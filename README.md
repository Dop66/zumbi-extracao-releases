## ⬇️ Baixar o jogo

**Windows:** [Baixar o instalador do launcher](https://github.com/Dop66/aether-outbreak-releases/releases/download/launcher/AetherOutbreakLauncher-setup.exe) (`AetherOutbreakLauncher-setup.exe`)

1. Abra o instalador. Ele instala só para o seu usuário, sem pedir administrador.
2. Abra o **Aether Outbreak Launcher**, escolha seu Nickname e o preset gráfico.
3. Clique em **JOGAR**. O launcher baixa o jogo e se atualiza sozinho.

Tinha o launcher antigo ("Zumbi Extração")? Ele não recebe mais atualizações: instale o novo uma vez. Seus saves continuam.

Se o Windows mostrar "O Windows protegeu o seu computador", clique em **Mais informações → Executar assim mesmo**.

**Linux:** [Baixar aether-outbreak-linux.zip](https://github.com/Dop66/aether-outbreak-releases/releases/latest/download/aether-outbreak-linux.zip), extraia e rode `./AetherOutbreak.x86_64` (se precisar: `chmod +x AetherOutbreak.x86_64`).
